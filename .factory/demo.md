# Daily Range demo

Open `/demo` or `/?demo=1` to enter the one-click sample. The sample uses the
public 28 August 2026 map and starts with relay 1 already pinned. Place relay 2
to complete the route.

The demo banner stays visible while sample mode is active. **Reset demo** clears
all `demo:daily-range:*` browser storage and starts the sample again. **Start
for real** clears that demo storage and opens today’s real map.

Real completions use `daily-range:<date>` storage keys. Demo completions use
only `demo:daily-range:<date>` keys, so the sample never reads or writes a real
game record.
